# JurisPulse v1.0.0-rc1 Release Notes

We are pleased to introduce JurisPulse v1.0.0-rc1, an enterprise legal intelligence workspace.

### Key Capabilities
- **Legal Entity Timeline**: Chronological event mapping and automated order sheets.
- **Deep Research**: Indian case law retrieval with pgvector semantic similarity.
- **AI Drafter**: Context-aware pleading and bail petition generation.
- **Enterprise Security**: Role-based access control and tenant isolation.
